One line, at most 140 characters: the funniest excuse a robot vacuum could offer for missing a spot.

> I didn’t miss that spot — my LIDAR classified the dust pile as load-bearing furniture, so I left it standing.

Run it with Node 22.18+:

```sh
node main.ts
```

It prints the line to stdout and writes it to `/output/entry.txt`.
